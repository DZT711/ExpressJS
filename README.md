# ExpressJS

## run command

```cmd
cd /workspaces/ExpressJS/ExpressJS/template &&
npm start
```

or with auto-reload:
```cmd
cd /workspaces/ExpressJS/ExpressJS/template &&
npx nodemon ./bin/www

cd /workspaces/ExpressJS/pug &&
npx nodemon app.js
```

## run load test command

```cmd
cd /workspaces/ExpressJS/ExpressJS/template &&
node loadtest.mjs
```
